Download


Homebrew (macOS, Linux)

brew tap microconfig/microconfig && brew install microconfig

Check it works: microconfig -v


Native binary

Native builds for macOS, Linux (including Alpine) and Windows. No Java required. Download a zip from the latest release on GitHub.

Executable jar

Runs anywhere with Java 8+. Download microconfig.jar from GitHub or Maven Central.

java -jar microconfig.jar -e dev

Core library

To build configs from your own Java code, add io.microconfig:microconfig-core as a dependency.

IDE plugin

Navigate, resolve and preview configs in IntelliJ IDEA and other JetBrains IDEs. See the plugin page.
